# آب‌وهوا — هواشناسی
برنامه اندروید آب‌وهوا با پیش‌بینی ۱۰ روز آینده، جستجوی شهر و منطقه (تهران، کرج و...) و ویجت صفحه اصلی. ساخته‌شده با کاتلین.
- فایل نصب: `Weather.apk` (پکیج `com.aksell.weather`، نسخه ۱٫۷)
- ویجت صفحه اصلی با حداکثر ۵ شهر قابل انتخاب از داخل برنامه و دکمه تازه‌سازی ↻
- نسخه وب/HTML برنامه: `weather-app.html`
- منبع آب‌وهوا: Open-Meteo (رایگان، بدون نیاز به کلید) + OpenStreetMap برای جستجوی منطقه‌ها
